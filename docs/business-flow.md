# Meeheng ERP Business Flow

## 1. รับวัตถุดิบเข้า

ผู้ใช้บันทึกรายการในแท็บ `รับเข้า`

- เพิ่มยอดใน `Inventory`
- บันทึก ledger ใน `StockMovements`
- ถ้ากรอกต้นทุนต่อหน่วย ระบบจะบันทึกค่าใช้จ่ายใน `Expenses`

## 2. ผลิตสินค้า

ผู้ใช้เลือก `ลูกชิ้นสูตรใหญ่` หรือ `หมูยอสูตรหลัก` แล้วกรอกจำนวนชุดผลิต

- ระบบอ่านสูตรจาก `Recipes`
- ระบบเช็กวัตถุดิบใน `Inventory`
- ถ้าสต๊อกไม่พอ ระบบจะหยุดและแจ้งรายการที่ขาด
- ถ้าสต๊อกพอ ระบบตัดวัตถุดิบเป็น `PRODUCTION_CONSUME`
- ระบบเพิ่มสินค้าสำเร็จรูปเป็น `PRODUCTION_OUTPUT`
- ระบบบันทึกประวัติใน `ProductionLogs`

## 3. ขายสินค้า

ผู้ใช้บันทึกยอดขายในแท็บ `ขาย`

- ระบบตัดสต๊อกสินค้าสำเร็จรูปเป็น `SALE_OUT`
- ระบบบันทึกยอดขายใน `SalesLogs`
- Dashboard รวมยอดขายวันนี้และยอดขายเดือนนี้

## 4. บันทึกค่าใช้จ่าย

ผู้ใช้บันทึกค่าใช้จ่ายในแท็บ `บัญชี`

- ค่าแก๊ส
- ค่าแผง
- ค่าแรง
- ค่าขนส่ง
- รายจ่ายทั่วไป

Dashboard จะนำยอดขายเดือนนี้ลบค่าใช้จ่ายเดือนนี้เพื่อแสดงกำไรเบื้องต้น

## 5. ตรวจ Dashboard

เจ้าของดูภาพรวมได้ทันที:

- ยอดขายวันนี้
- ยอดขายเดือนนี้
- ค่าใช้จ่ายเดือนนี้
- กำไรเดือนนี้
- จำนวนชุดผลิตวันนี้
- รายการวัตถุดิบต่ำกว่าเกณฑ์
