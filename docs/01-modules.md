# Meeheng ERP Modules

## Inventory

ดูแลวัตถุดิบ เครื่องปรุง บรรจุภัณฑ์ อุปกรณ์โรงงาน และสินค้าสำเร็จรูป พร้อมบันทึก ledger ทุกครั้งที่มีการเคลื่อนไหว

## Production

ใช้สูตรผลิตลูกชิ้นและหมูยอ เช็กวัตถุดิบก่อนผลิต ตัดสต๊อกอัตโนมัติ และเพิ่มสินค้าสำเร็จรูป

## Vendor Sales

บันทึกยอดขายจากหน้าร้านหรือแม่ค้า ตัดสต๊อกสินค้าสำเร็จรูป และรวมยอดขายเข้ากับ Dashboard

## Accounting

บันทึกค่าใช้จ่าย เช่น ค่าแก๊ส ค่าแผง ค่าแรง และค่าใช้จ่ายทั่วไป พร้อมสรุปกำไรเบื้องต้นรายเดือน

## Owner Dashboard

เจ้าของดูยอดขาย การผลิต ค่าใช้จ่าย กำไร และรายการสต๊อกต่ำกว่าเกณฑ์ได้จากหน้าแรก
