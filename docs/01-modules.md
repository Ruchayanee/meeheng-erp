# Meeheng ERP Modules

## Inventory
ดูแลวัตถุดิบ เครื่องปรุง ถุง สติ๊กเกอร์ และสินค้าสำเร็จรูป

## Production
จัดการสูตรการผลิตและการตัดสต๊อกอัตโนมัติ

## Vendor Sales
แม่ค้ากดขายผ่านมือถือแบบ realtime

## Accounting
รวมรายรับ รายจ่าย ค่าแก๊ส ค่าแผง และคำนวณกำไร

## Owner Dashboard
เจ้าของดูยอดขาย realtime และรายงานทั้งหมด
