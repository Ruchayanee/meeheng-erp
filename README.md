# Meeheng ERP

ระบบ ERP สำหรับโรงงานมีเฮงฟู้ด (Meeheng Food)

## Core Modules
- Inventory
- Production
- Vendor Sales
- Accounting
- Owner Dashboard

## Tech Stack
- Google Apps Script
- Google Sheets
- HTML/CSS/JS
- GitHub

## Business Flow
รับวัตถุดิบ → ผลิต → ตัดสต๊อก → แม่ค้าเบิก → แม่ค้าขาย → Dashboard realtime → สรุปกำไรขาดทุน
